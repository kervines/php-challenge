# 🟢 Desafio 1 — Contagem de Números

## 📋 Descrição

Crie um programa que receba uma lista de números inteiros e realize algumas operações sobre esses números.

O objetivo deste exercício é praticar conceitos básicos de lógica de programação, como:

- Estruturas de repetição;
- Estruturas condicionais;
- Listas/arrays;
- Contadores;
- Acumuladores;
- Comparações.

---

## 🎯 Objetivo

Dada uma lista de números inteiros, o programa deverá informar:

1. Quantos números são pares;
2. Quantos números são ímpares;
3. Qual é o maior número;
4. Qual é o menor número;
5. Qual é a soma de todos os números.

---

## 📥 Entrada

O programa deverá receber uma lista contendo números inteiros.

### Exemplo

```text
[10, 5, 8, 3, 12, 7]
```

---

## 📤 Saída esperada

Para a entrada:

```text
[10, 5, 8, 3, 12, 7]
```

O resultado deverá ser:

```text
Pares: 3
Ímpares: 3
Maior: 12
Menor: 3
Soma: 45
```

---

## 📌 Regras

- A lista pode possuir qualquer quantidade de números.
- Os números podem ser positivos ou negativos.
- Não utilize funções prontas para encontrar o maior e o menor número.
- O maior e o menor número devem ser encontrados através da sua própria lógica.
- A soma deve ser calculada percorrendo a lista.
- A quantidade de números pares e ímpares também deve ser calculada através de lógica própria.

---

## 🧪 Exemplos

### Exemplo 1

Entrada:

```text
[1, 2, 3, 4, 5]
```

Saída:

```text
Pares: 2
Ímpares: 3
Maior: 5
Menor: 1
Soma: 15
```

### Exemplo 2

Entrada:

```text
[10, 20, 30]
```

Saída:

```text
Pares: 3
Ímpares: 0
Maior: 30
Menor: 10
Soma: 60
```

### Exemplo 3

Entrada:

```text
[-10, -5, 0, 8]
```

Saída:

```text
Pares: 3
Ímpares: 1
Maior: 8
Menor: -10
Soma: -7
```

---

## 🚫 Restrições

Evite utilizar funções como:

```text
max()
min()
```

ou equivalentes da linguagem escolhida.

A ideia é desenvolver a lógica manualmente.

---

## 💡 Dicas

Pense em quais informações precisam ser armazenadas durante o percurso da lista.

Você provavelmente precisará de variáveis para:

```text
pares
ímpares
maior
menor
soma
```

Para verificar se um número é par, utilize o conceito de **resto da divisão**.
